# Assets

Put the exported character here.

```bash
cp ../exports/test01/avatar.glb ./avatar.glb
```

`avatar.glb` is not committed: it is a 1.6 MB binary derived from a test photograph and
regenerated by `run_pipeline.sh`. The manifest at `exports/test01/manifest.json` records
its SHA-256, so a copy can be checked against a rebuild:

```bash
sha256sum avatar.glb exports/test01/avatar.glb
```

In the app, copy the file to `app/src/main/assets/avatar/avatar.glb` and load it with
`AvatarView.load("avatar/avatar.glb")`.
