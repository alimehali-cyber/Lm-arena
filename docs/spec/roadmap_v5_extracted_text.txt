3.4 Physics model + modeling-assumptions box
a_i = Σ_{j≠i} G·m_j·(r_j − r_i) / (|r_j − r_i|² + ε_soft²)^{3/2}  — the acceleration form of F = G·m₁·m₂/r², all 190
pairs per force pass. Earth pulls the Sun; the Moon pulls both ( earthPerturbsSun , moonAffectsBoth  prove it forever).
Massless bodies (test marbles, wormhole mouths) exert no gravity — falls out of m_j = 0, no special case — while fully feeling it.
Modeling assumptions (stated once, referenced everywhere): 1. Gravity is Newtonian only (no relativity is computed anywhere,
including black holes). 2. Preset distances and radii are not to scale; masses, G, velocities are real. 3. Mergers assume equal
density — r′ = (r₁³+r₂³)^⅓ conserves volume and, under equal density, conserves density exactly; real bodies differ (a real merger
of a gas giant and a rocky planet would not). 4. Wormhole teleport preserves velocity — a modeling choice for undefined
physics. 5. The slingshot preview is a test-particle approximation (see §3.9).
Derived physics for features: circular speed √(GM/r); escape speed √(2GM/r); specific orbital energy ε_orb = v²/2 − GM/r (bound
⇔ ε_orb < 0); eccentricity vector from state vectors. Collision radius = visual radius in scene meters. No zoom in v1.
3.5 Integrator — Velocity Verlet (KDK)
fun step(dt: Double) {
    for (i in 0 until n) { vx[i] += ax[i]*dt/2; vy[i] += ay[i]*dt/2 }   // KICK ½
    for (i in 0 until n) { x[i] += vx[i]*dt;  y[i] += vy[i]*dt  }       // DRIFT
    computeAccelerations()                                              // softened O(n²)
    for (i in 0 until n) { vx[i] += ax[i]*dt/2; vy[i] += ay[i]*dt/2 }   // KICK ½
    simTime += dt
    resolveCollisions(); validateState()
}
Selected over Euler (unbounded energy growth), symplectic Euler (bounded but sloppier at identical cost), and RK4 (non-
symplectic secular drift, 4× cost). Deterministic, time-reversible, ~15 lines. Earth orbit = 8,766 steps/orbit at DT=3600. 
Synchronization rule: every mutating intent (drag move/release, mass/radius/velocity change, add/remove) runs 
computeAccelerations()  before the next substep so the first kick never uses a stale acceleration (Auditor B13; test 39).

3.8 Numerical integrity — 3 layers
Prevent: ε_soft = 10⁶ m keeps forces finite through near-contact.
Repair: per-substep NaN/Inf scan → rollback restores all SoA arrays AND simTime; events appended during the failed
substep are discarded (the accumulator is not rolled back — it lives in the ViewModel and is governed by the debt-discard
rule) → emit NumericalFailure ; 3 consecutive rollbacks → auto-pause with a calm notice.

3.9 Rendering — Compose Canvas (font-agnostic)
One TabletopCanvas  owns the scene; chrome is ordinary Compose above. State read only inside the draw lambda (zero
recomposition per frame). Zero allocation in the draw lambda — all Brush/Path/PathEffect/TextMeasurer preallocated; static
background layers via drawWithCache . Shadows: soft radial-gradient ellipses (never setShadowLayer ). Bodies are marbles:
shadow → radial-gradient base → optional rim → restrained specular → selection ring → cached label. No rotation, surfaces,
atmospheres, terminators. Double→Float  exactly once, at the draw boundary. The canvas is pinned L TR
( CompositionLocalProvider(LocalLayoutDirection provides Ltr) ); only chrome mirrors under RTL. Typography: the
app's existing default font — no font resources, no font dependencies, no typography edits.
Trails: preallocated ring buffers, 240 points, one point recorded per rendered frame → a constant ~4 s observed-motion window
at 60 fps; trail extent scales with visible motion (perceptually correct at every speed). Drawn as low-alpha stroked paths with 2–
3 stepped-alpha segments.
