## The `backgroundExecutor!!` story (Z-BUILD3) and the T3 replacement

Declaration (CameraFrameObserver.kt, unchanged by both fixes):

    private val backgroundExecutor: ExecutorService = Executors.newSingleThreadExecutor { r ->
        Thread(r, "CameraFrameObserver").apply { isDaemon = true }
    }

Exact compiler error that `!!` fixed (CI run 33872051539, buildlogs/619a6dee.log, since
removed from the tree per this item; artifact `gradle-build-log`/`unit-test-log` now
carries future logs):

    e: file:///home/runner/work/Lm-arena/Lm-arena/app/src/main/java/com/alijafari/red/astronomy/ui/screens/CameraFrameObserver.kt:58:29
      Argument type mismatch: actual type is '@Nullable() Executor?', but '@NonNull() Executor' was expected.

The val is genuinely non-null (non-null type `ExecutorService`, initialized from a
non-null factory). T3 therefore replaced `!!` with a minimal inference fix — hoisting
into a local val typed as the declared parameter type inside the same `lazy` block:

    val executor: java.util.concurrent.Executor = backgroundExecutor
    ...
    setAnalyzer(executor) { imageProxy: ImageProxy -> ... }

No runtime assertion remains. CI (assembleDebug + the new unit-tests job) confirms the
build on this commit.
