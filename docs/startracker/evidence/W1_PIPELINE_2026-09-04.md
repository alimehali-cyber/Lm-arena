## Two KIND-B solver improvements required to make the pipeline honest (both mutated-proofed)

1. **verify → refit → re-verify** (Tetra3-style, in LostInSpaceSolver after the S2 gate
   passes): Davenport q-method over ALL full-field matched pairs (catalog→camera
   convention), accepted only if re-verification still passes. The RANSAC attitude's
   accuracy is bounded by its 2063″ inlier threshold; the refit reaches the
   centroid-noise scale. Mutation: bypassing the refit fails the FULL_LOCK test
   (RMS 1.11 px > 1.0 → MARGINAL).
2. **verification-based confidence**: confidence = max(legacy formula, full-field
   fraction) when the gate passes — RANSAC inlier count under-counts because quad-match
   correspondences cluster on a few anchor stars (4/395 in the E2E). Mutation: reverting
   to legacy-only fails the FULL_LOCK test (conf 0.19 < 0.7 → MARGINAL).

Also: FullFieldVerifier prediction cone widened 31.75°→60° (must be ≥ sensor
half-diagonal 51.6°; corners were unmatchable — detections are the denominator, so S2/S3
results are unaffected), and Result gains mean/median matched residuals (pipeline Rule-4
statistic = MEDIAN; a handful of merged-blob tail matches skews the mean).

## W1 finding (flagged)

Flux-ranked anchor selection (TOP_N=10 brightest) is vulnerable to merged blob pairs in
dense fields when brightness diversity is low: with a flat amp floor, merged pairs
(~2× flux) displace real stars as anchors and NO quad matches. The E2E render uses a
realistic 1:25 dynamic range; a robustness fix (rank anchors by peak, reject
near-duplicate centroids) is future work, not needed for the E2E or S3 profiles.
